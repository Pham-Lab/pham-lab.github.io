#### PAFit package
<!--[![codecov](https://codecov.io/gh/thongphamthe/PAFit/branch/master/graph/badge.svg)](https://codecov.io/gh/thongphamthe/PAFit)-->
[![Downloads from CRAN](https://cranlogs.r-pkg.org/badges/PAFit?color=blue)](https://CRAN.R-project.org/package=PAFit)
[![Downloads from CRAN](https://cranlogs.r-pkg.org/badges/grand-total/PAFit?color=blue)](https://CRAN.R-project.org/package=PAFit)
[![CRAN](https://www.r-pkg.org/badges/version/PAFit?color=blue)](https://cran.rstudio.com/package=PAFit)
[![License: GPL v3](https://img.shields.io/badge/License-GPL%20v3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
<br>
An R package for estimating preferential attachment and fitnesses in growing complex networks. This package implements the methods proposed [in these papers](https://cran.r-project.org/web/packages/PAFit/citation.html). You can find it on [GitHub](https://github.com/thongphamthe/PAFit) or [CRAN](https://cran.r-project.org/web/packages/PAFit/index.html). 
<br>
For installation:
{% highlight R %}
require(devtools)
install_github("thongphamthe/PAFit@devel")
{% endhighlight %}

#### Multivariate Counterfactual Distribution with Optimal Transport
[![License: MIT
c](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/license/mit)
<br>
Python code for [estimating the multivariate counterfactual distribution by robust optimal transport methods](https://proceedings.mlr.press/v236/pham24a.html).  You can find it on [GitHub](https://github.com/thongphamthe/scalable-counterfactual).

#### FoFaF package
[![License: GPL v3](https://img.shields.io/badge/License-GPL%20v3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
<br>
An R package, developed mainly by [Masaaki Inoue](https://www.researchgate.net/profile/Masaaki-Inoue), for [estimating friends-of-friends effect in temporal networks](https://www.sciencedirect.com/science/article/pii/S175115771930269X).  You can find it on [GitHub](https://github.com/minoue637/FoFaF).
<br>
For installation:
{% highlight R %}
require(devtools)
install_github("minoue637/FoFaF")
{% endhighlight %}
