# Pham Lab

Source files for the [Pham Lab website](https://pham-lab.github.io/).

## Updating the site

- Pages: `_pages/`
- News: `_news/`
- Publications: `_bibliography/papers.bib`
- Images and other assets: `assets/`
- Site settings: `_config.yml`

Commit source changes to `main`. The workflow in `.github/workflows/pages.yml` builds the site with Jekyll and publishes it to GitHub Pages.

## GitHub Pages setup

In the repository settings, select **Pages → Build and deployment → Source → GitHub Actions**.
